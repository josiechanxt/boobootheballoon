# Burst Booboo!

This is a static p5.js game and can be published directly with GitHub Pages.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your publishing branch (usually `main`) and the **`/(root)`** folder, then save.

GitHub will provide the public URL shortly after the deployment completes. Open that URL in Chrome. Microphone controls require permission; GitHub Pages uses HTTPS, which Chrome requires for microphone access.
